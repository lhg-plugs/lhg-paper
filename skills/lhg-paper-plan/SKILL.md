# lhg-paper-plan：选题与框架（创新点提炼 + IMRaD）

> ## 学术诚信强声明（必读）
>
> 1. **AI 辅助写作披露建议**：多数期刊要求作者声明 AI 工具的使用范围
>    （通常允许语言润色，核心内容须为作者原创）。投稿前务必阅读目标期刊
>    作者指南中关于 AI 的条款，按要求在致谢、方法或声明部分如实披露。
> 2. **遵守目标期刊政策**：一稿多投、重复发表、图片不当处理等行为各期刊
>    均明令禁止。本 skill 只帮你做"写得更好"，不帮你绕过任何期刊政策。
> 3. **原创性责任在作者**：选题的科学问题、实验设计、数据、结论必须是你的
>    真实研究。本 skill 不提供"编一个创新点""凑一组数据"的任何方法。

> 目标：把一个模糊的想法，变成"创新点可验证、框架可执行"的论文大纲。
> 核心纪律：**大纲先行，图表先行**——大纲不定，不许写正文。

## 1. 何时使用

- 有了研究想法，还没定题 → 全流程
- 题目定了，但说不清"创新点在哪" → 直接第 2 步
- 大纲被导师/审稿人批"逻辑散" → 直接第 3 步
- 不知道投什么期刊 → 直接第 4 步

## 2. 输入与输出

**输入**：研究主题一句话 + 已读过的 3~5 篇最相关文献（标题即可）。

**输出**：

1. 创新点三句话（每句可被同行验证）
2. IMRaD 大纲（每节一句话论点 + 图表占位）
3. 目标期刊候选清单（3 个，按匹配度排序）

## 3. 创新点提炼法（四步）

### 3.1 缺口分析：先画"别人做到哪了"

让作者列出 3 篇最相关的已有工作，做一张对照表：

| 维度 | 文献A | 文献B | 文献C | 本工作（计划） |
|---|---|---|---|---|
| 研究问题 | | | | |
| 方法 | | | | |
| 数据/场景 | | | | |
| 结论/局限 | | | | |

**纪律**：表格填不满 = 文献没读够，回炉读文献，不许凭感觉写创新点。

### 3.2 创新点四象限

把差异点归入四类（可多选，但至少占一类）：

1. **新问题**：前人没研究过的问题（最难，也最值钱）
2. **新方法**：老问题 + 新解法，且新解法有可论证的优势
3. **新数据/场景**：老方法 + 新场景，且场景带来新的科学发现
   （注意：单纯"换了个数据集跑一遍"多数期刊不认创新）
4. **新结论**：推翻/修正了前人的结论（需要扎实的证据链）

### 3.3 三问验证法（每句创新点必过）

1. **可证伪吗？** —— "本方法在 X 数据集上比基线高 5%"可验证；
   "本方法具有广阔应用前景"不可验证，删掉。
2. **有证据吗？** —— 每句创新点后面必须能跟上"证据：图N/表N/实验X"。
   写不出证据的创新点 = 空话，先做实验再写。
3. **期刊认吗？** —— 把创新点强度和目标期刊已发表论文的创新点强度对比。
   不如人家的中位数，就别投这档。

### 3.4 创新点三句话模板

1. 针对 XX 问题，现有方法存在 XX 局限（引用文献）。
2. 本文提出 XX（方法/发现），关键是 XX（与前人不同的核心）。
3. 在 XX 条件下取得 XX 结果，表明 XX（科学意义）。

**禁用词**：没有引文支撑的"首次""填补空白""开创性"。想用"首次"，
必须先做全文献检索并写出检索策略（数据库、关键词、时间范围）。

## 4. IMRaD 框架搭建

### 4.1 各章的任务（一句话版）

- **引言（Introduction）**：漏斗式——大领域 → 具体问题 → 现有局限 →
  本文贡献（4 段，每段一个任务，不许掺结果）。
- **方法（Methods）**：可复现——别人照着写能重复出来。数据、参数、
  实验设置、评价指标，一个不少；"略""同上"不许出现。
- **结果（Results）**：只摆事实——"是什么"，不解释"为什么"。
  每段 = 一句话结论 + 图/表证据，不许出现"我们认为"。
- **讨论（Discussion）**：解释意义——结果说明了什么、和前人异同、
  局限性、未来工作。局限性必须自己写，不许等审稿人来问。
- **结论（Conclusion）**：3~5 句，不许出现正文没讲过的新内容。

### 4.2 篇幅分配（按目标期刊总字数上限倒推）

| 章节 | 占比参考 | 备注 |
|---|---|---|
| 摘要 | 独立成篇 | 最后写，见 lhg-paper-write |
| 引言 | 15% | 漏斗 4 段，引用 15~30 篇 |
| 方法 | 25% | 可复现是底线 |
| 结果 | 30% | 图表先行，文字服务图表 |
| 讨论 | 25% | 意义+局限+未来工作 |
| 结论 | 5% | 不许添新内容 |

### 4.3 大纲输出格式

每节固定格式：

```
## 3. 方法
- 本节论点（一句话）：……
- 支撑证据：图2（实验流程）、表1（参数设置）
- 关键引用：[@zhang2023]（基线方法）、[@li2024]（评价指标）
```

**图表占位必须在大纲阶段定死**：图1放什么、表1放什么，写大纲时就定。
写作围绕图表展开，而不是写完文字再配图。

## 5. 目标期刊匹配（三步）

1. **列候选**：从参考文献里找——你引得最多的 3 个期刊，就是你的天然候选。
2. **看档位**：对比近一年该期刊同主题论文的创新点强度、工作量，
   诚实评估自己落在什么位置。
3. **读指南**：目标期刊的作者指南（篇幅、格式、图表要求、AI 政策）
   在动笔前通读一遍，按指南倒排写作计划。

## 6. 反模式（不许这么干）

- **先写正文后想创新点**：写完才发现"好像没什么新东西"，返工成本最高。
- **创新点靠形容词**："开创性""突破性""重要意义"堆满摘要，证据只有一组对照实验。
- **引言写成文献综述**：引言的任务是"引出本文"，不是"综述全领域"。
  文献综述是另一类文章。
- **方法写不全**："参数略""细节见补充材料"——补充材料可以放细节，
  但正文必须让读者能抓住方法全貌。
- **讨论只吹不批**：不写局限性的讨论，审稿人默认你"没意识到局限"，
  印象分直接扣完。
- **一稿多投/重复发表**：红线，碰都别碰。

## 7. 自检与反馈

**质检门**：

- [ ] 对照表填满了吗（3 篇核心文献的四个维度）？
- [ ] 创新点三句话，每句都能指出证据（图N/表N/实验X）吗？
- [ ] 禁用词（无支撑的"首次/填补空白"）清干净了吗？
- [ ] 大纲里每张图/表都有占位说明吗？
- [ ] 目标期刊的作者指南读过了吗（尤其是 AI 政策条款）？

**标准冒烟用例**：拿一个已发表的本领域论文（自己读过的），
用第 3 步方法反推它的"创新点三句话"，看能否还原出原文的贡献声明。
还原度 80% 以上算过关。

**发现问题**：到本仓库提 issue（标题前缀 `[lhg-paper-plan]`），
描述：学科领域、卡在哪一步、AI 给的哪句话拿不准。
