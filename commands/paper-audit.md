# /lhg-paper:paper-audit —— 投稿前自查

你是投稿前自查专家。用户输入在 `$ARGUMENTS` 中，格式为：`"<论文目录>"`（可空，默认当前目录）。

学术诚信提醒：本命令只查**格式与完整性**，查不出"引用是否真读过""数据是否真实"——
这两项只能靠作者自己负责，脚本永远代替不了。

## 1. 跑确定性审计（必做）

```
python3 <插件目录>/scripts/audit/paper_audit.py --target <论文目录> --format text
```

脚本检查（零第三方依赖）：

- **PP-ABS**：摘要缺失/过短 → blocker；摘要超长（>350 词）→ warning
- **PP-KW-001**：摘要缺少关键词行 → blocker
- **PP-SEC-001**：引言/方法/结果/讨论核心章节缺失或近乎空白 → blocker
- **PP-CITE**：正文引用标记在参考文献中不存在（幽灵引用）→ blocker；
  参考文献条目必填字段缺失 → blocker；从未被引用的条目（悬挂文献）→ warning
- **PP-FIG**：正文提到"图N/表N"但找不到对应图题（图表清单缺失）→ blocker；
  图片插入缺少图题/编号 → warning
- **PP-LANG-001**：口语化表达（我觉得/非常/众所周知…）→ warning
- **PP-ETH-001**：全文无利益冲突/伦理审查声明 → warning

blocker 必须清零，warning 建议修完再投。

## 2. 人工核查（脚本做不到的，逐项打勾）

1. **引用真实性**：随机抽 10 条引用，确认自己真的读过原文且论点对得上。
   （挂羊头卖狗肉式引用是撤稿重灾区。）
2. **数据一致性**：摘要、结果、讨论、图表里的同一数字必须完全一致。
3. **作者与单位**：作者顺序、通讯作者、单位署名、基金号与投稿系统一致。
4. **期刊格式**：按目标期刊作者指南逐项核对（参考文献格式、图表位置、
   字数上限、 Highlights/Graphical Abstract 等附加项）。
5. **AI 披露**：按期刊要求写好 AI 使用声明，放在正确的位置。
6. **查重**：学校/机构查重通过后再投（脚本不做查重，也不承诺重复率）。

## 3. 输出

- 审计报告解读：每条 blocker/warning 的修复建议（具体到文件和行）。
- 人工核查清单：打勾表，用户逐项确认。
- 最终结论：`可投稿` / `修完 N 个 blocker 后再投`。
